# How to Submit Your Work

**In one line:** fork the repo → do each day from the checklist → fill that day's worksheet → paste
the worksheet link in the WhatsApp group.

Always work in **your own fork**. You will never edit the upstream repo, so nobody overwrites anybody.

---

## 1. Fork the repo (once)

1. Open **https://github.com/kriti-on-git/TNX-AIML**
2. Click the **Fork** button (top-right). You now have your own copy under your GitHub username.

From now on, **use your fork's URL** (`https://github.com/<your-username>/TNX-AIML`), not the original.

## 2. Pick your track (once)

Open your fork and go to your track inside Week 1:

- Track A — `week-01/track-a/checklist.md`
- Track B — `week-01/track-b/checklist.md`
- Track C — `week-01/track-c/checklist.md`

Read the **Day 1** block and the *Documentation* links at the end of the checklist.

## 3. Do the day, and tick the checklist

1. Watch the video for the day and run the code yourself.
2. In **your fork**, open your track's `checklist.md`, click the **pencil / Edit** icon (top-right).
3. Change each `- [ ]` to `- [x]` as you finish it.
4. Click **Commit changes** (green button), then *Commit changes* again.

## 4. Fill that day's worksheet

1. In your fork, open `worksheet/day-N.md` (for example `week-01/track-a/worksheet/day-1.md`).
2. Click the **pencil / Edit** icon.
3. Write your answer under **Your answer** for every question. For code questions, paste the **code and
   its output**.
4. Click **Commit changes**.

Do this **daily**, not at the end of the week.

## 5. Copy the link to your filled worksheet

Open your filled-in `day-N.md` in your fork and copy the URL from the browser address bar. It should
look like:

```
https://github.com/<your-username>/TNX-AIML/blob/main/week-01/track-a/worksheet/day-1.md
```

> Copy the link from **your fork**, not from `kriti-on-git/TNX-AIML` — only your fork has your answers.

## 6. Post it in the WhatsApp group

Send one message per day using the report format below.

### Daily report format (copy-paste)

```
*AIML Week 1 — Daily Report*
Name:
Track: A / B / C
Day: 1 (Mon 12 Oct)
Topics done:
Worksheet link:
Time spent: __ min | Confidence (1-5):
```

Example:

```
*AIML Week 1 — Daily Report*
Name: Asha Sharma
Track: A
Day: 1 (Mon 12 Oct)
Topics done: Setup, Python history, VS Code setup, hello.py
Worksheet link: https://github.com/asha-s/TNX-AIML/blob/main/week-01/track-a/worksheet/day-1.md
Time spent: 75 min | Confidence (1-5): 4
```

## Final Monday (19 Oct 2026)

No new topics. Use the day to finish any missed days, then post your final report with the Day 7
worksheet link.

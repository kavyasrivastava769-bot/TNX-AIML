## How to fill in a worksheet

1. Open the day's file **in your fork** and click the pencil / Edit icon.
2. Scroll to each question and write your answer under **Your answer**. For code questions, paste the
   program **and** its output.
3. Commit your changes. Do this daily, not at the end of the week.
4. The final Monday (19 Oct) is for finishing anything still blank.

> Run every program you write. An answer copied from a video is worth nothing; an answer you ran is
> worth everything.
